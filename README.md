# Gerenciador de Faturas

Aplicação web pessoal para acompanhar faturas compartilhadas, compras parceladas, pagamentos e gastos do titular.

## Uso

Acesse a versão publicada em:

https://viniciusfrosa.github.io/Gerenciador-de-Faturas/

Os dados são armazenados localmente no navegador. Use **Configurações > Backup & Restauração** para exportar ou restaurar os dados.
